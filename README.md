# English Lab

Личная платформа изучения английского: план 90 дней B1 → B2, ежедневные задачи,
тренажёр слов с интервальным повторением, библиотека ресурсов, прогресс.

Открыть: https://vikagladysheva07-source.github.io/english-lab/

## Данные

Прогресс хранится в браузере устройства (localStorage). Никакие данные
не отправляются никуда, пока не включена синхронизация.

## Синхронизация между устройствами

1. В Supabase → SQL Editor выполнить `supabase.sql`
2. В платформе → Настройки → Синхронизация: вставить Project URL и anon key
3. Нажать «Сохранить и синхронизировать» — появится ключ доступа
4. На втором устройстве ввести те же три значения

Ключи хранятся только в браузере и в этот репозиторий не попадают.
